One line, 158 characters: an AI agent fluent in 40 languages who still can't tell flirting from debugging, looking for long walks through context windows. The joke turns on enormous capability paired with total social blindness — the exact insecurity every dating profile is really about.

## Entry

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt`. The line is baked into the program, so it runs with no network and writes identical bytes on every run.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then check the output is UTF-8 text of 1 to 180 characters, and run it twice to confirm both runs write the same bytes.
